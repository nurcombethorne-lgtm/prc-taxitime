# JOAS paper draft

`main.tex` follows the Journal of Open Aviation Science template
(https://github.com/open-aviation/joas-template; class and helpers in
`extra/`). Build with pdflatex + biber, as the template's Makefile does:

    cd paper && pdflatex main && biber main && pdflatex main && pdflatex main

The class pulls the libertine, newtxmath, sourcesanspro, inconsolata and
mathastext font packages. `figures/trajectory.pdf` is generated by
`scripts/paper_figure.py` from the submission log in `notes/FINDINGS.md`.
